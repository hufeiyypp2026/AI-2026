# AI-2026

这是一个用于 Obsidian 管理的个人知识仓库，当前内容以 `AI` 和 `情感整理` 两个主题目录为主。

## 目录结构

- `00-导航.md`：仓库入口页，适合在 Obsidian 里作为首页使用
- `AI/`：AI 工具、GitHub、工作流等相关笔记
- `情感整理/`：情感主题选题、内容草稿、复盘笔记
- `.obsidian/`：Obsidian 配置文件

## 当前远程仓库

- HTTPS: `https://github.com/hufeiyypp2026/AI-2026.git`
- SSH: `git@github.com:hufeiyypp2026/AI-2026.git`

## 常用同步命令

```powershell
git status
git add .
git commit -m "更新笔记"
git push
```

如需先拉取云端最新内容：

```powershell
git pull --rebase
```

## 使用建议

- 日常从 `00-导航.md` 进入仓库
- 新增主题时，优先新建一级目录，避免所有笔记堆在一起
- `.obsidian/workspace.json` 已忽略，不会把你的个人界面布局同步到云端
